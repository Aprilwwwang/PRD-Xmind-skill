# Prompt Patterns

## From PRD to XMind

```text
Use $build-xmind-test-cases to read this PRD and generate a test case mind map.
Output both Markdown source and .xmind file.
Use Chinese, include P0/P1/P2 priority, and put unclear rules under 假设与待确认问题.
```

## From HTML Prototype to XMind

```text
Use $build-xmind-test-cases to inspect this HTML prototype and generate UI, interaction, and workflow test cases in XMind format.
Cover tabs, cards, forms, tables, notifications, empty/error states, and mobile layout risks.
```

## From Existing Test Case Table to XMind

```text
Use $build-xmind-test-cases to convert this test case table into a readable XMind map.
Keep test case IDs, priorities, preconditions, steps, expected results, and requirement references.
```

## Warehouse Administrator Digital Employee

```text
Use $build-xmind-test-cases for the warehouse administrator digital employee project.
Generate an XMind test case map covering inbound receiving, outbound shipping, and inventory count placeholders.
Do not invent detailed inventory count rules before the workflow is confirmed.
```
